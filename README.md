# CS6120 Coursework

Coursework for [CS6120: Natural Language Processing](https://course.ccs.neu.edu/cs6120f26/#/) at Northeastern University.

## Assignments

### 1. Autocomplete

Build a word-level autocomplete over the Shakespeare corpus, backed by a Trie data structure for O(prefix length) prefix lookups.

- **Notebook**: [`assignment1.ipynb`](./assignment1.ipynb)
- **Live demo**: [Shakespeare Writing Pad](https://zuccamia.github.io/cs6120-coursework/shakespeare-writing-pad/) — a book-styled writing pad that surfaces suggestions from the Bard's vocabulary as you type
- **Demo source**: [`demos/shakespeare-writing-pad/`](./demos/shakespeare-writing-pad/)
